# 순자산 계산법: 자산·부채 분류와 정리 주기

월급이 오르고 지출을 줄였는데도 형편이 나아졌는지 잘 모르겠다면, 한 장짜리 '내 재무상태표'를 만들어 볼 때입니다. 소득과 지출이 한 달 동안의 흐름이라면, 순자산은 특정한 날에 찍은 사진입니다. 사진을 같은 방식으로 꾸준히 찍어야 변화가 보입니다.

## 순자산이란: 공식 통계의 분류 방식

국가데이터처·금융감독원·한국은행이 함께 작성하는 가계금융복지조사는 **순자산 = 자산 − 부채**로 계산하고, 자산을 금융자산과 실물자산으로, 부채를 금융부채와 임대보증금으로 나눕니다. 실물자산은 시장가격으로 평가하고, 자산·부채는 매년 3월 31일을 기준으로 조사합니다(2025 조사 기준, 국가데이터처).

개인이 정리할 때도 이 틀을 빌리면 빠뜨리는 항목이 줄어듭니다.

| 구분 | 세부 분류 | 예시 |
|---|---|---|
| 금융자산 | 현금성 | 입출금 통장, 예금, 비상자금 |
| | 투자·저축 | 적금, 펀드, 주식, 연금저축 적립금 |
| | 돌려받을 돈 | 임차인으로서 맡긴 전·월세 보증금 |
| 실물자산 | 부동산 | 보유 주택, 토지 |
| | 기타 | 자동차 등 |
| 금융부채 | 담보·신용 | 주택담보대출, 전세대출, 신용대출, 마이너스 통장 사용액 |
| | 결제 예정 | 카드 할부 잔액, 할부금융 잔액 |
| 임대보증금 | 돌려줄 돈 | 임대인으로서 받은 보증금 |

*세부 분류와 예시는 개인 정리용으로 이 글에서 정한 것입니다. 예를 들어 임차인으로 맡긴 보증금은 '돌려받을 돈'이라는 성격에 맞춰 금융자산 칸에 넣었습니다.*

## 가상 예시로 순자산 계산하기

**가상 예시** — 전세에 사는 2인 가구, 기준일 3월 31일

| 자산 | 금액 | 부채 | 금액 |
|---|---|---|---|
| 예금·입출금 | 2,000만 원 | 전세대출 | 1억 원 |
| 전세보증금 | 2억 원 | 신용대출 | 1,000만 원 |
| 연금저축 적립금 | 1,000만 원 | 카드 할부 잔액 | 200만 원 |
| 자동차(중고 시세) | 1,500만 원 | | |
| **자산 합계** | **2억 4,500만 원** | **부채 합계** | **1억 1,200만 원** |

순자산 = 2억 4,500만 원 − 1억 1,200만 원 = **1억 3,300만 원**

같은 표에서 '바로 쓸 수 있는 돈'만 따로 보면 이야기가 달라집니다. 예금·입출금 2,000만 원에서 곧 갚아야 할 카드 할부 잔액 200만 원을 빼면 1,800만 원입니다. 순자산이 커도 대부분이 보증금이나 자동차처럼 묶인 자산이라면, 급한 지출에 대응할 여력은 이 숫자로 판단해야 합니다.

## 정리 주기와 평가 원칙

- **기준일 고정**: 매달 말일이나 분기 말처럼 같은 날짜에 정리해야 비교가 됩니다.
- **평가 방식 고정**: 부동산·자동차는 한 번 정한 평가 기준(예: 같은 시세 조회처)을 계속 씁니다. 기준을 바꾸면 실제 변화가 아니라 계산 방식 때문에 숫자가 출렁입니다.
- **보수적 평가**: 자동차처럼 시간이 지나면 가치가 줄어드는 자산은 높게 잡지 않습니다.
- **부채는 잔액으로**: 처음 빌린 금액이 아니라 기준일 현재 남은 원금을 적습니다.

정리 주기는 월 1회가 부담이라면 분기 1회도 충분합니다. 중요한 건 빈도보다 같은 규칙을 지키는 일입니다.

## 비상자금 기준 세우기

비상자금은 실직, 질병, 갑작스러운 수리처럼 예정에 없던 지출을 대출 없이 버티기 위한 돈입니다. 모두에게 맞는 정답 금액은 없으므로, **월 필수지출 × 버틸 개월 수**로 스스로 기준을 정합니다.

**가상 예시** — 월 필수지출(고정지출 + 최소 생활비) 200만 원

| 버틸 기간 | 목표 금액 | 이런 경우에 검토 |
|---|---|---|
| 3개월 | 600만 원 | 맞벌이로 소득원이 둘이고 고용이 안정적 |
| 6개월 | 1,200만 원 | 외벌이, 프리랜서, 부양가족이 있음 |

비상자금은 수익보다 **바로 꺼낼 수 있는지**가 중요합니다. 예금이라면 2025년 9월 1일부터 예금보호한도가 원금과 이자를 합해 1억 원으로 올랐다는 점도 참고할 수 있습니다(금융위원회). 실적에 따라 지급액이 달라지는 펀드 등은 보호 대상이 아닙니다.

## 순자산 정리 체크리스트

- [ ] 기준일과 평가 방식을 정해 표 맨 위에 적었다
- [ ] 보증금(받은 것·맡긴 것)을 빠뜨리지 않았다
- [ ] 카드 할부·마이너스 통장 사용액을 부채에 넣었다
- [ ] '바로 쓸 수 있는 순자산'을 따로 계산했다
- [ ] 비상자금 목표와 현재 금액의 차이를 적었다
